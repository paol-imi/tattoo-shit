# Inbox

Tutto ciò che non è ancora smistato: link Pinterest, frasi, intuizioni al volo.

- Una nota per "lancio", con nome `AAAAMMGG-descrizione.md`. Dentro va bene qualsiasi cosa: un link, una riga, una domanda.
- I pin si annotano come link (`https://www.pinterest.com/pin/…`). Le immagini Pinterest non entrano nel repository.
- Durante il triage Claude Code propone dove collegare ogni elemento (spunto, idea, simbolo, o uno spunto nuovo), io confermo e lui sposta e collega.
- Ciò che non va da nessuna parte può restare qui: va bene così.
